# Liquidity Map V2.2 — Amount Density Walls

## 目标

让黄色墙框与肉眼看到的热力颜色使用同一套“挂单量比例”语义，而不是：

- 过去 24 小时 P95；
- 周边均值 3 倍；
- 单纯按当前截面 Top 10% 排名。

## 默认热力色阶

默认颜色模式改成：

```text
当前已完成盘口截面
买卖盘分别计算
本侧最厚价格格 = 100%
其他价格格 = 当前挂单量 / 本侧最厚挂单量
```

因此前端 50% 就真正表示“该价格格挂单量约为本侧最厚格的 50%”。

配色改成高对比 CoinGlass 风格：

```text
象牙白 → 桃色 → 鲑红 → 玫红 → 深洋红
```

色阶上限限制为 100%。达到上限的格子继续保持最深色，不会因为把上限拖到 100% 以上而全图一起变浅。

## 墙定义

### 单点小阻力/支撑

一个价格格达到：

```text
>= 本侧最厚挂单的 50%
```

只标记为 `POINT`，不是主墙。

### 主墙

默认必须同时满足：

```text
附近至少 3 个价格格 >= 40%
整个区域至少包含 4 个 >= 18% 的价格格
归一化挂单总量 >= 1.5
价格范围覆盖率 >= 35%
```

含义：

- 40%+ 深色格是墙的锚点；
- 18%+ 较浅格允许夹在中间，构成肉眼看到的“深浅混合密集区”；
- 浅色格不能单独把无关区域串成墙；
- 单个 50% 深色点不会被升级成宽主墙。

## 时间追踪

- 默认持续 20 秒、出现率 70% 后确认；
- 允许短暂缺失 2 个快照；
- 每个时间片只使用当时已经完成的盘口；
- 后续扩大的墙不会反向改写过去的边界。

## 当前边界

本版仍然只做墙识别人工审计，尚未使用 Raw Trades 判断：

- 触碰前撤单；
- 成交消耗；
- 快速补单；
- 吸收；
- 打穿后收回。

在人工审计通过前，禁止用于正式回测或实盘下单。

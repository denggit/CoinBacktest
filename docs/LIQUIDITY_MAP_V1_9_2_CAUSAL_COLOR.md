# Liquidity Map V1.9.2 — Causal Rolling Color Normalization

## 修复目标

热力图颜色不再使用当前请求区间的全量 Q99。默认颜色基线改为：

- 过去 24 小时；
- 买盘 / 卖盘分别统计；
- 按距离当前中间价的区间分别统计；
- 当前时刻不进入自己的历史阈值（`closed=left`）；
- 查询结束时间延长后，已经显示的历史颜色保持不变。

## 默认颜色定义

每个时间点、方向、距离带先计算该截面的 P99 深度，再使用过去 24 小时这些截面 P99 的滚动 P99 作为该时刻的颜色封顶。

默认显示：

```text
颜色模式：过去窗口因果滚动 P99 · 对数
颜色窗口：24 小时
颜色分位数：99%
```

窗口可以改为：

```text
24 小时 = 1 天
72 小时 = 3 天
168 小时 = 1 周
```

## 因果边界

- 不使用可视区间未来数据；
- 不使用整月或整段查询全量分位数；
- 正常查询会额外读取颜色窗口长度的历史数据作为 warmup，但 warmup 不显示在图中；
- 数据集最早时刻没有历史时，只使用该时刻已经完成的截面做因果启动，不读取后续数据。

## 其他

- 不修改 Books 原始数据；
- 不修改 `features.npz` / `heatmap.npz`；
- 不修改价格轴、时间轴和墙识别规则；
- 无需重新 prebuild。

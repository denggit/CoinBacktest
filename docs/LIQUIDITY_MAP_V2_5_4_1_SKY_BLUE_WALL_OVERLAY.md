# Liquidity Map V2.5.4.1 — Sky-Blue Wall Overlay

- POINT wall border width becomes 2.0 px;
- wall fill opacity becomes 0.028;
- heatmap colours, period-end snapshots, wall detector thresholds, cache format, compact JSON and gzip are unchanged.

No Liquidity Map rebuild or period-end cache rebuild is required.

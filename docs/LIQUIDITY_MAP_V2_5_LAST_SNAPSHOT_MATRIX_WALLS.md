# Liquidity Map V2.5 — Last-Snapshot Matrix Walls

## 目标

彻底废弃 V2.4 的“短周期截面切段 + 相邻帧追踪”墙识别方式，改为与 15m 热力图和未来实盘一致的数据语义：

- 历史 K 线：只使用该 K 线结束前最后一个有效订单簿快照；
- 实盘当前 K 线：使用当前最新订单簿快照，后续 Books 到达时覆盖当前列；
- 5s 数据只作为离线回放和寻找每根 K 线最后快照的来源，不再直接产生 5s 墙切片；
- 所有墙判断只使用当前时刻及之前的数据。

## 二维输入

墙检测器输入为：

```text
横轴 = K 线
纵轴 = $1 价格格
单元格 = 当前挂单量 / 因果滚动 24h 稳健高位挂单参考量
```

默认颜色/墙阈值保持同一口径：

```text
>= 50%：深色核心
>= 30%：墙体主体
>= 15%：浅色连接层
```

## 新墙定义

### 单点墙口 `POINT`

一个或两个固定价格格，在连续多根 K 线中长期偏深。它可作为小支撑/阻力和未来做 T 的位置，但不自动视为主仓防线。

### 主墙 `MAIN`

固定价格附近多个价格格在滚动历史中共同偏深：

- 默认观察过去 4 小时；
- 至少先积累 4 根 K 线；
- 15%+ 连接层默认时间覆盖率 60%；
- 30%+ 主体层默认时间覆盖率 45%；
- 50%+ 核心层默认时间覆盖率 15%；
- 允许最多 2 个浅色/空白价格格；
- 当前列仍需保留至少 8% 挂单比例，否则进入暂时变浅/结束流程；
- 墙边界使用当前及过去几根已知 K 线做因果稳定，不读取未来。

## 生命周期

```text
STABLE -> PERSISTENT -> MAJOR
```

若一堵已识别墙暂时变浅，最多允许缺失 2 根 K 线，时间线显示为 `FADING`。重新出现且价格区域稳定时，继续使用同一墙身份。

## 因果保证

- 不用当前 K 线之后的盘口；
- 不把后来扩大的墙范围回写到早期；
- 不把移动的单点墙累计成一堵宽墙；
- 墙检测和热力颜色共用同一份因果 24h 深度比例；
- 当前版本只用于 Analyze Tool 人工审计，未验证前禁止进入回测和实盘。

## 是否需要重新 prebuild

不需要。V2.5 直接读取现有 `heatmap.npz` 中的周期末精确盘口字段：

```text
end_depth_base
end_depth_usd
end_order_count
```

# ETH 1D+4H Momentum Breakout V3

## 定位

V3 是 Momentum Breakout 独立引擎的第三版。

V2 已经把 2023 假突破亏损大幅压缩，但 high / turbo / ultra 版本仍然在 2023 小亏。V3 不使用年份、月份、日期过滤，而是加入一个通用市场状态规则：

> 当 4H ADX 已经偏高时，多头突破更容易变成趋势末端追高，因此保留信号，但降低仓位。

核心变更：

```text
long_mature_breakout = long_signal and adx > 16
quality_mult *= 0.50
```

这不是删除交易，而是降低成熟阶段突破的风险敞口。

## 反未来函数约束

脚本继续遵守：

```text
1. 1D regime 使用 shift(1) 后映射到 4H
2. 1W regime 使用 shift(1) 后映射到 4H
3. Donchian entry / exit 使用 rolling(...).shift(1)
4. 当前 4H 收盘确认信号
5. 下一根 4H open 执行
6. 当前 bar close 更新的新 stop 下一根 bar 才生效
7. 不允许同一根 K 线内新 stop 立刻触发
8. 不使用年份、月份、日期过滤
```

## 默认手续费

默认 `fee_rate=0.00055`，约等于完整开平仓 0.11%。

## 参数鲁棒性检查

核心参数 `mature_long_quality_mult` 和 `mature_long_adx_threshold` 没有精细调到某个特殊值。粗略测试中，ADX 阈值 14、16、18、20、22，降权 0.4、0.5、0.6、0.7 都能不同程度改善 2023 和 PF。默认采用较粗的 `adx > 16` 与 `0.50`。

## 当前判断

V3 已经是 Momentum Breakout 的主引擎候选。

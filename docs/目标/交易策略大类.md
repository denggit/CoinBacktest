| 类别      | 是否适合个人云服务器 |     核心程度 |
| ------- | ---------: | -------: |
| 趋势延续    |       非常适合 |       主线 |
| 均值回归    |       非常适合 |       主线 |
| 波动率策略   |       非常适合 |       主线 |
| 订单流与流动性 |  适合，但不能太高频 |       主线 |
| 资金费率与基差 |  适合，但工程较复杂 |       补充 |
| 时间与事件驱动 |         适合 | 过滤器或独立策略 |
| 做市与被动挂单 |       有限适合 |  不建议作为主线 |

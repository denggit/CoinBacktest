# Research Charter — ETH Latent Liquidity Pool Path Learning V1

## 最终目标

构建一个 Long/Short 对称的潜在止损池与扫损路径模型，在高置信度流动性区域附近实现短结构止损、较高名义仓位和厚盈亏比，同时严格控制真实账户风险。

最终执行目标可以包含提前限价挂单，但只有在模型能够同时预测下列变量后才允许研究挂单：

1. 潜在止损/清算流动性密度；
2. 未来触碰概率；
3. 预计扫穿深度；
4. 触发后反转、延迟反转和接受延续概率；
5. 可实现的真实结构止损与净盈亏比。

## 不允许的研究方式

- 不允许把任意 Swing Low/High 直接定义成止损池；
- 不允许把一根长影线定义成完整扫损事件；
- 不允许先写两三个主观形态，再围绕它们调参数；
- 不允许让“止损池位置模型”看到扫损当秒或未来爆量；
- 不允许通过高杠杆掩盖过远止损；
- 不允许在R01直接优化收益。

## 分层模型架构

### Model A — Latent Pool Location

在触发前，根据多尺度路径预测某个价格区域是否可能积累大量止损、清算或脆弱仓位。

### Model B — Release Intensity

当区域被触发时，根据1秒Trade、Range与Footprint判断实际释放强度、冲击效率和扫穿深度。

### Model C — Reversal vs Acceptance

使用触发后当时已可见的路径，预测：

- 浅扫立即反转；
- 深扫立即反转；
- 继续延伸、稳定后反转；
- 市场接受新区域并继续突破；
- 混合或不可交易。

### Execution

最后才比较提前挂单、扫后确认入场和分层仓位。执行层不能反向污染位置模型的训练标签。

## Swing的正确定位

Swing只允许使用已完成并因果确认的15m、30m、1H、4H和1D结构。秒级、1m、3m、5m等微观Swing禁止进入模型。

不能只看最近一个Swing。每一个已确认且尚未被第一次真实扫过的历史Swing High/Low都必须保留；不因距离远或年龄久而自动删除。模型可以学习其年龄、距离、数量、层级和跨周期汇聚，但Swing永远不是候选准入条件，也不是流动性的定义。

真正的主研究对象是潜在止损、清算和脆弱仓位流动性。模型必须同时学习：

- 价格与成交在区域内的累积、停留、反复穿越和拒绝；
- 推动、回撤、压缩、扩张和多层波段嵌套；
- 成交额、笔数、Delta、大单、冲击效率和压力却不走；
- 追价拥挤、潜在持仓堆积和流动性释放Episode；
- 后续Range、Footprint、OI/Funding、清算和Books增量。

15m以上Swing只是上述完整路径中的一组辅助位置特征。模型还必须能够发现：

- 没有标准Swing、但追价与仓位路径形成的脆弱区域；
- 大波段内部多个小波段叠加形成的连锁止损；
- 震荡边缘、成交成本断层和加速路径形成的其他流动性池。

## R01定位

R01先从实际发生的广义流动性释放事件出发，回看严格事件前路径，通过固定12类发现聚类寻找重复出现的前置路径家族。R01不是最终位置预测模型；它为R02提供训练目标与路径家族。

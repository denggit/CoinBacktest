# ETH 1m Raw Volume Shadow Research 当前结论与下一步计划

2026-07-10

## 一、当前研究目标

当前这条研究线的目标不是找最高 `mean_return` 的单一策略，而是找适合 portfolio 平滑曲线的 MHF / MF 边缘信号。

优先目标：

1. 交易次数尽可能多。
2. 胜率尽可能高。
3. 单笔 mean_net 可以不特别高，但不能太薄到被手续费吃掉。
4. fee2 后仍然接近正，最好为正。
5. MAE 可控，坏交易能尽早暴露。
6. MFE 出现速度快，入场后短期有赚钱效应。
7. 不靠少数大赢家撑收益。
8. 2023 / 2024 / 2025 / 2026 尽量稳定，尤其 2025 不能崩。
9. 回撤低，最大连续亏损低，适合组合进现有 portfolio。

核心思路：

> 先从路径中分析，不要拿着固定策略倒推结果。先找 MFE / MAE / bad path / good path，再决定过滤条件和退出逻辑。

---

## 二、已经验证过的结论

### 1. 裸长影线本身不是 edge

原始事件：

* 放量长下影线，下一根 open 做多。
* 放量长上影线，下一根 open 做空。

结论：

> 裸长影线直接交易，扣 0.11% 成本后整体不是正期望。

不管 long / short，raw baseline 大多是负的。
所以不能简单地说“下影线做多 / 上影线做空”就是策略。

---

### 2. 但长影线之后确实存在明显 MFE 空间

Raw shadow path atlas 里看到：

* 下影线做多，后续经常有不错 MFE。
* 上影线做空，后续也有 MFE，不是完全没信息。
* 问题不是没有浮盈空间，而是 MAE 深、路径杂、最终收益捕获差。

结论：

> 长影线事件里有赚钱路径，但 raw universe 太脏，需要过滤坏交易和识别值得持仓的结构。

---

### 3. 简单 exit 救不了 raw universe

已经测过：

* event low / high 硬止损。
* close beyond extreme stop。
* allow 1 sweep。
* allow 2 sweep。
* sweep 后 15 根不 reclaim 就出。
* reclaim mid / full structure 后再失败退出。

结论：

> 在原始长影线全集上，单靠简单 exit 不能把整体变成 edge。

所以当前不是先继续优化 exit，而是应该先找“哪些交易值得进 / 值得持仓”。

---

### 4. 有效单条件过滤主要来自 vol_regime 和 range_pct

`03_filter_probe` 里，单条件测试结果显示：

真正有明显改善的方向：

1. `vol_regime`
2. `event range_pct`

其他单条件目前没有单独形成明显正期望：

* volume_ratio
* close_pos
* wick_share
* wick_atr
* prior_move
* trend
* session
* delta_against_entry
* taker_against_entry

这些不是永远没用，但作为单独过滤条件，目前不是主线。

### 5. 当前最重要主线：lower shadow long + mid_high_vol / extreme_vol

必须记录的主线：

```text
lower_volume_shadow_long
keep mid_high_vol or extreme_vol
horizon = 60
```

当前表现大概：

```text

events_per_month ≈ 26
mean_net ≈ +0.2447%
win_rate ≈ 56.82%
PF ≈ 1.445
bad_rate ≈ 11.61%
positive_years = 4/4
```

年份表现大概：

```text

2024: mean +0.3675%, win 62.20%, PF 1.70
2025: mean +0.0712%, win 50.74%, PF 1.11
2026: mean +0.4032%, win 64.33%, PF 1.85
```

结论：

> 这是当前 raw shadow 研究线里最值得继续深挖的方向。
> 2025 偏弱但没有完全崩，说明有继续优化价值。

---

### 6. range_pct 是次级高频线索

`range_pct >= 0.35` / `range_pct >= 0.50` 方向有一定提升。

优点：

* 交易次数更多。
* 比 vol_regime 更接近高频平滑目标。

缺点：

* PF 薄。
* 回撤大。
* 2025 / 2026 变弱。
* 单独作为策略还不够。

结论：

> range_pct 不能单独作为最终策略，但应该作为后续辅助过滤或分层诊断特征保留。

---

### 7. bad trade signature 方向验证有效

坏交易定义：

```text
fast adverse sweep + MFE < 0.3%
```

下影线做多就是：

```text
入场后很快扫 event low，并且后面 MFE < 0.3%
```

上影线做空镜像：

```text
入场后很快扫 event high，并且后面 MFE < 0.3%
```

坏交易明显集中在：

1. very_low_vol / 低波动环境。
2. event range 太小。
3. volume_ratio 不够。
4. 前面没有足够反向挤压 / panic move。
5. 影线爆发性不够。
6. 回收速度不够。

结论：

> 从“找坏交易共性”入手是对的。
> 先过滤风险大的交易，可能比直接找好交易更适合高胜率平滑型 edge。

---

### 8. 扫低次数 / 扫高次数是重要路径变量

Raw path 里看到：

* sweep 0 次质量最好。
* sweep 1 次还能接受。
* sweep 2 次开始明显变差。
* sweep >= 3 基本是坏路径。

但注意：

> sweep_count 是未来路径统计，不能直接作为入场条件。
> 它只能指导我们找事件当下可见的坏交易共性，或者设计持仓后的风控逻辑。

---

### 9. short 暂时不是主线，但不能永久丢掉

上影线 short 在 raw atlas 里也有 MFE，但目前：

* raw entry 不行。
* simple exit 不行。
* filter probe 没有形成清晰主线。
* bad trade 画像有一些镜像特征，但还没形成稳定候选。

当前优先级：

```text
主线：lower shadow long
次线：upper shadow short 暂时观察，后续可用 range bar / footprint 再复核
```

## 三、现在不要做什么

暂时不要做：

1. 不要直接把所有条件组合起来优化。
2. 不要用未来标签直接做入场过滤。
3. 不要上来就机器学习交易。
4. 不要继续在 raw universe 上乱测 exit。
5. 不要只按 mean_net 排名。
6. 不要为了高收益牺牲交易次数和胜率。
7. 不要把 240bar 高收益结果当主线，当前更应该看 60bar 短期赚钱效应。

## 六、高频赚钱效应定义

理想 MHF / 高频平滑信号应该具备：

```text
入场后 5-60 分钟内经常先给浮盈；
MAE 不深；
坏交易很快暴露；
胜率高；
交易数够多；
不靠少数大赢家；
手续费后仍有薄正 edge。
```

可以定义几类路径标签：

### 1. strong_short_term_edge

```text
60bar 内 MFE >= 0.5%
并且 MAE > -0.5%
并且 time_to_mfe <= time_to_mae
```

### 2. tradable_short_term_edge

```text
60bar 内 MFE >= 0.3%
并且 MAE > -0.7%
```

### 3. bad_fast_adverse

```text
15bar 内快速扫 event low
并且 60bar 内 MFE < 0.3%
```

### 4. noisy_trade

```text
MFE 有，但 MAE 也很深，路径不适合高胜率平滑策略
```

## 八、下一版要测试的单维度

在 `lower long + mid_high/extreme_vol + horizon60` 内部，逐个测试：

1. `range_pct` 分层
   看 range 是否越大越好，还是过大反而容易极端风险。

2. `volume_ratio` 分层
   看是否量能爆发不足的下影线更容易失败。

3. `wick_share` 分层
   看下影线占比是否能区分质量。

4. `close_pos` 分层
   看收盘回收到 K 线高位是否更好。

5. `prior_move_against_30` / `prior_move_against_120`
   看是否必须先有足够下跌 / panic move。

6. `event_range_pct` 与 ATR 关系
   看是不是必须是相对当前波动足够大的事件。

7. `delta_ratio` / `taker_buy_ratio`
   看主动卖压吸收是否有帮助，但不要作为当前第一主线。

8. `session`
   只做诊断，不优先作为过滤主线。

9. `fast reclaim`
   事件后 1-3 根是否快速 reclaim event mid / event high。

10. `fast adverse sweep`
    入场后 5 / 10 / 15 根是否快速扫 event low。

## 九、机器学习是否需要

当前不建议直接上机器学习做交易信号。

更合理的顺序：

1. 先用规则和分层分析把主线拆清楚。
2. 如果特征很多、单维度发现不够，再用 ML 做 diagnostic。
3. ML 先做 bad-trade classifier 或 short-term-edge classifier。
4. 用模型输出 feature importance / SHAP / split gain。
5. 再把模型发现转成简单规则。
6. 最后再进入 candidate backtest。

ML 的用途不是一开始就黑箱交易，而是帮助回答：

```text
哪些事件容易成为 fast adverse + low MFE？
哪些事件容易 60bar 内 MFE >= 0.5%？
哪些特征最能解释短期赚钱效应？
```

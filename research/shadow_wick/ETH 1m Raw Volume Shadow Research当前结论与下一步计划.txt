# ETH 1m 放量长影线研究阶段总结

## 一、研究目标

这条研究线的最终目标不是追求单笔最高收益，而是寻找适合 ETH portfolio 和带单曲线的 MHF/MF 补充型 edge：

* 交易次数尽可能多；
* 胜率较高；
* 短期赚钱效应明显；
* 坏交易能尽快暴露；
* 回撤和连续亏损可控；
* 不依赖少数超级大赢家；
* 可以根据不同信号质量进行仓位、退出和风险分层；
* 最终用于平滑现有 LF/MF 策略的收益曲线。

默认研究成本按 OKX 完整一买一卖 0.11% 计算。

所有结果必须遵守：

* closed bar 生成信号；
* 下一根 bar open 入场；
* 禁止未来函数；
* 禁止为了高收益过拟合；
* 最终候选必须经过成本、延迟和鲁棒性测试。

默认研究区间：

```text
start-date = 2023-01-01
end-date = 2026-06-30
warmup-start-date = 2022-01-01
```

# 二、最初 Idea

最初假设：

```text
放量超长下影线 → 下一根开盘做多
放量超长上影线 → 下一根开盘做空
```

并考虑：

* 重复出现时加仓；
* 反向影线时平仓或反手；
* 影线极值作为潜在结构止损；
* 结合成交量、delta、波动率、趋势、session、footprint、range bar 等寻找 edge。

研究过程中没有直接把这个 Idea 写成策略，而是按路径逐步拆解：

```text
raw event
→ MFE/MAE 路径
→ 简单退出
→ 单条件过滤
→ 坏交易画像
→ 短期赚钱效应
→ 不同 edge 方向评分
→ 影线外止损诊断
```

# 四、01 Raw Shadow Path Atlas 结论

原始事件量大约：

```text
lower standard ≈ 51,664
upper standard ≈ 47,878
lower extreme ≈ 13,320
upper extreme ≈ 11,716
```

## 主要结论

### 1. 裸长影线直接交易没有 edge

不论：

* 下影线做多；
* 上影线做空；
* 持有 5/15/30/60/120/240 分钟；

扣除 0.11% 成本后，整体都没有稳定正期望。

因此：

> “出现长影线就反向开仓”不是完整策略。

### 2. 但长影线之后存在明显 MFE

原始长影线虽然最终收益不理想，但后续经常出现较大浮盈：

```text
lower long MFE mean ≈ +0.95%
upper short MFE mean ≈ +1.05%
```

这说明：

> 影线事件不是完全无信息，真正问题是事件全集太脏、MAE太深、持仓路径差异很大。

### 3. 扫影线极值次数非常重要

路径中发现：

```text
sweep 0 次：质量最好
sweep 1 次：通常仍可接受
sweep 2 次：质量开始明显变差
sweep >= 3：多数变成坏路径
```

但 `sweep_count` 是持仓后才能知道的路径变量，不能直接作为入场条件。

# 五、02 Simple Exit Probe 结论

已经测试：

* 碰 event low/high 硬止损；
* 收盘突破影线极值止损；
* 允许一次扫；
* 允许两次扫；
* 扫后 15 根内不 reclaim 退出；
* reclaim mid/full structure 后再次失败退出。

结果：

> 在原始十几万长影线事件全集上，简单 exit 不能把整体变成 edge。

没有任何简单退出方案形成稳定正期望。

因此确认：

```text
Raw universe 太脏
仅靠 exit 无法拯救
必须先找到值得交易的子结构
```

# 七、04 Bad Trade Signature Probe 结论

定义坏交易：

```text
fast adverse sweep
+ horizon60 MFE < 0.3%
```

下影线做多对应：

```text
入场后短时间内扫 event low
并且未来 60 分钟最大浮盈不足 0.3%
```

## 坏交易高发特征

坏交易明显集中在：

* very_low_vol；
* event range 太小；
* volume ratio 不足；
* 前面没有足够下跌或 panic move；
* 影线爆发性不足；
* 回收速度不足。

这证明了：

> 从“找坏交易共性”入手是有效研究方法。

相比继续寻找越来越严格的好交易，先剔除明显高风险路径更符合高频、高胜率、平滑曲线的目标。

# 十、上影线做空结论

当前结论：

```text
下影线做多：已有明确主线
上影线做空：暂时没有稳定主线
```

上影线 short 在 raw atlas 中有较大 MFE，说明不是完全无信息。

但目前：

* raw short 没有 edge；
* simple exit 没有救回来；
* 单条件过滤没有形成高频、高胜率、稳定主线；
* 少量正结果样本小，不符合当前目标。

后续更可能需要不同结构：

```text
下跌趋势中的反弹失败
failed breakout
主动买量衰竭
上影线后跌回 event mid/low
range bar 失败突破
footprint 买盘被吸收
```

因此 short 暂时降为次线，不永久放弃。

# 十一、06 Direction Scorecard 的框架结论

不同方向不应该直接全部硬过滤，而应该承担不同角色。

## Core Base Sleeve

候选：

```text
prior_move_against_720 >= 2%
prior_move_against_120 >= 2%
trend_downtrend
```

目标：

* 保持相对较多交易；
* 提高胜率；
* 作为基础资金层；
* 使用相对标准的仓位和退出。

## Profit Booster

候选：

```text
range_pct >= 0.80%
wick_atr >= 1.50
extreme_vol
volume_ratio 3.0-5.0
```

目标：

* 高质量低频；
* 可以提高仓位系数；
* 允许更大的盈利空间；
* 不替代 base sleeve。

## Confidence Overlay

候选：

```text
moderate absorption
```

目标：

* 不一定决定是否交易；
* 用于信号加权；
* 决定入场优先级或仓位倍率；
* 后续接 footprint/CVD。

## Defensive / Risk State

候选：

```text
fast adverse sweep
no reclaim
repeated sweep
weak range
very_low_vol
```

目标：

* 降仓；
* 不加仓；
* 提前退出；
* 暂停信号；
* 不是独立赚钱方向。

# 十二、07 影线外止损研究结论

测试了：

```text
hard_wick_stop
buffered_wick_stop
close_below_wick_stop
```

## 结果

没有任何一个可以直接保留为最终止损规则。

Base 主线加止损后：

```text
hard stop diagnostic mean ≈ -0.019%
buffered stop diagnostic mean ≈ -0.028%
close-below stop diagnostic mean ≈ -0.012%
```

全部明显削弱原始 edge。

## 原因：误伤严重

以 hard stop 为例：

```text
stop_hit_rate ≈ 74.93%
stop_hit后仍MFE >= 0.5% ≈ 59.98%
stop_hit后仍MFE >= 1.0% ≈ 40.40%
```

以 close-below stop 为例：

```text
stop_hit_rate ≈ 65.74%
stop_hit后仍MFE >= 0.5% ≈ 51.69%
stop_hit后仍MFE >= 1.0% ≈ 34.04%
```

说明：

> 很多优秀反弹交易会先扫低，甚至收盘跌破 event low，再开始反弹。

因此：

```text
event_low 不是简单硬止损线
event_low 是风险状态切换线
```

## 不扫低的交易极强

例如没有触发 hard stop 的交易：

```text
trades ≈ 270
mean_net_60 ≈ +1.475%
win_rate ≈ 96.30%
bad_rate = 0%
```

说明：

```text
不碰 event_low = 高质量路径
碰 event_low = 进入风险观察状态
碰 event_low 后直接砍 = 太早
碰 event_low 后不能恢复 = 真正失败
```

# 十三、当前对止损的最新理解

下一步不再研究简单：

```text
价格碰 event_low → 立即止损
```

而应该研究：

## 影线外失败确认

可能的结构：

```text
1. sweep_then_no_reclaim_mid
扫低后不能重新站回 event mid。

2. sweep_then_no_reclaim_high
扫低后不能重新站回 event high。

3. close_below_low_and_no_reclaim
收盘跌破 low 后仍无法快速收回。

4. deeper_sweep_failure
不是第一次扫 low 就退出，而是进一步深破才认错。

5. repeated_sweep_failure
多次扫 low 且始终不能恢复。

6. post_reclaim_failure
已经 reclaim 后又重新失守关键结构。
```

这不是 time exit，而是：

```text
持仓路径进入风险状态
→ 观察是否恢复
→ 无法恢复才退出
```

> 原始放量长影线不是策略，但“中高/极端波动环境下、此前已经充分下跌的放量长下影反弹”具有明确短期赚钱效应。当前真正需要解决的不是有没有 edge，而是如何在不损失大量交易数的情况下，识别扫低后能够恢复的好路径与无法恢复的坏路径，并用 Base、Booster、Confidence、Defensive 四类评分实现不同仓位和退出管理。

New/future ICT MSS2 runs default to `2026-08-15 23:59:59`.

### 1. Official naked 1m OHLCV

Data access remains in `src.data_feed.OKXDataLoader`; the utility is only a cache/prebuild wrapper.

```text
python tools\prebuild_okx_ohlcv.py --symbol ETH-USDT-SWAP --timeframe 1m --start-date 2026-07-01 --end-date "2026-08-15 23:59:59"
```

### 2. 1m trade bars

```text

```

## Not required for current R07

Do **not** prebuild these just for R07:

- range bars;
- range footprints;
- 400/5000-depth books / offline liquidity map;
- OI / funding / mark / liquidation inputs;
- Binance futures metrics.

Only prebuild them when a later frozen research question explicitly uses them.

If a future ICT family reintroduces range-footprint context, use the existing combined builder rather than separate repeated raw-trade passes:

```text
python tools\prebuild_okx_range_all.py --symbol ETH-USDT-SWAP --start-date 2026-07-01 --end-date 2026-08-15 --range-pcts 0.0015 0.002 0.0025 --price-step 1
```

Books and derivatives are deliberately excluded from the default prebuild because they are large/coverage-sensitive and are not inputs to the current price-action/FVG study.
